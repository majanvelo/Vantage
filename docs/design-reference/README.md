# docs/design-reference

Visual reference for the app UI. This folder holds **HTML mockups** of app
screens — they are for **visual direction only**, NOT functional code. Do not
wire them up or treat them as live prototypes; they exist to show look-and-feel
and layout intent.

Current contents:
- `reel-app-concept.html` — the Reel app concept mockup (three phone screens:
  Create Event → Syncing clips → Multicam auto-cut switcher), plus design notes.
  Use this for visual direction on the mobile UI (dark theme, amber/teal/red
  accents, JetBrains Mono + Manrope, mono timecodes, clip waveform cards, the
  multicam lane view, "regenerate" re-cut affordance).
